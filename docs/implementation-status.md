# 実装状況

## 採用方針

- 方針B: `KOBEDAI_dash` に実行時依存しない独立Pythonパッケージ
- 同一のstdioサーバーをClaude Code、Claude Desktop、Codex Desktopから利用
- SQLite WALとファイルロックにより、複数クライアントから同じローカルDBを共有
- 長時間同期は別プロセスのjobとして開始し、MCP呼び出し自体は即時応答
- 本人アカウント／ローカル保存／読み取り中心。認証再試行は1回まで
- テスト、アンケート、出席はメタデータだけを取得し、開始・回答・登録を禁止

## 選択済み機能

1. `get_changes`: 新規、更新、非公開化と変更フィールドを履歴化
2. OCR: 画像と低文字量PDFページをTesseractで抽出（任意のローカル依存）
3. PDF以外: DOCX、PPTX、XLSX、TXT、CSV、主要画像形式を抽出
4. 状態取得: 課題、テスト、アンケート、出席の期限・公開期間・状態
5. `build_study_context`: 授業内検索結果を項目／ファイル／ページ引用つきで返却
6. `export_materials`: 設定済みルート内へ授業名／教材名で安全に整理コピー
7. 更新通知: 教材、お知らせ、課題等の新規・変更通知と確認済み管理

## 旧機能の移植

BEEF+、BEEF+ Venture、システム情報学部、学年暦PDF、Newsnet、
うりぼーネット、大学メールのパーサー／取得アダプター、および分類、
重複統合、提出済み推論、Google Calendar差分ロジックを独立移植済みです。
旧11 MCPツールも同名で登録しています。

## 検証済み範囲

- パーサー、文書抽出、DB UPSERT、変更履歴、通知、検索、引用、エクスポート
- テスト／アンケート等の操作URL拒否
- 同期jobの多重起動防止、構造化結果保存
- 旧DBの非破壊データ移行（資格情報・Cookieは対象外）
- 実stdioハンドシェイクと23ツールの列挙
- 日本語・空白を含む絶対パスでの3クライアント設定生成
- wheel/sdistビルド、MCPB schema検証・pack・再読込

## 実機でのみ確認できる事項

- 現在のKNOSSOS SSO、BEEF+/CampusSquare DOM、ダウンロード一時URL
- 実アカウントごとの授業・お知らせ・課題表示
- Claude Code／Claude Desktop／Codex Desktop各UIでの登録・権限表示
- Tesseract日本語言語データを導入した端末での実教材OCR精度
- Google OAuth同意後の大学メール取得

これらは実装不足ではなく、ユーザー認証・実教材・各デスクトップアプリを必要とする
実機受け入れ試験です。
